# Online Bus Reservation System (OBRS)

A web-based bus reservation system built using PHP, MySQL, Bootstrap, HTML, CSS, and JavaScript.

## Features

- User registration and login
- Email OTP verification
- Bus schedule management
- Seat selection and reservation
- Booking and ticket management
- Admin dashboard
- Support ticket functionality

## Technologies Used

- PHP
- MySQL
- HTML5 and CSS3
- Bootstrap
- JavaScript
- Composer and PHPMailer

## Local Setup

1. Install XAMPP and start Apache and MySQL.
2. Copy the project folder into `C:\xampp\htdocs\obrs`.
3. Create a MySQL database named `obrs`.
4. Import your project database SQL backup into phpMyAdmin.
5. Configure your local database credentials in `config/db_connect.php`.
6. Configure email settings locally if email OTP functionality is required.
7. Install Composer dependencies if they are not already installed.
8. Open `http://localhost/obrs/` in your browser.

## Security Note

Do not commit passwords, email app passwords, database credentials, or private configuration files to GitHub.
